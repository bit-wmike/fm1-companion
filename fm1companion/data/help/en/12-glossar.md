# Glossary

The terms used in the app – briefly explained. You can find each of them with the search at the top left.

| Term | Meaning |
|---|---|
| **Backup** | Complete backup of an FM-1: projects, presets and settings in one file. Stored in `~/FM-1/Backups`, with a separate folder for each device. See [Backups](app://page/backups). |
| **Custom firmware** | A firmware that does not come from M-VAVE, e.g. Melodee, Skiff or SLOOP. |
| **Demo mode** | Start with `fm1-companion --demo`: three simulated FM-1s, separate settings and a separate main folder. Your real data stays untouched. |
| **Device** | An FM-1 the app knows. Each one gets a name, colour, notes and its own backups – even if you have two. |
| **Editor** | The web editor that the installed firmware brings along itself. The app shows it on the [Editor](app://page/editor) page. |
| **Felucca** | The firmware family that Melodee, Skiff and SLOOP belong to. They share the editor protocol through which the app reads and writes backups, projects and presets. |
| **Firmware** | The program that runs in the FM-1. Find, switch and update it on the [Firmware+](app://page/discover) page (tab [Install & Versions](app://page/firmware)). |
| **FM voice (DX7)** | A sound in the format of the Yamaha DX7. Under Presets › FM Voices (DX7) you collect, listen to and create such sounds and send them to the FM-1. |
| **Kit** | A set of samples that goes into a sample slot of the FM-1 together (Skiff, SLOOP). |
| **Labels** | Keywords with which you organize and find samples and backups again. |
| **Main folder** | `~/FM-1` – this is where everything you work with yourself is stored: backups, projects, samples, kits, recordings. Can be changed in the settings. |
| **MIDI** | The language in which music devices exchange notes, controls and clock. The app talks to the FM-1 via USB MIDI. |
| **MIDI only** | A firmware without editor protocol (e.g. the original firmware). The app can then send notes and listen, but cannot read backups or projects. |
| **Original firmware** | The firmware from M-VAVE (V14, V15, V16). The way back is described under [Switching firmware](help:02-firmware). |
| **Pattern** | A sequence of notes on a track of the FM-1. Under Compose › From MIDI File a MIDI file is turned into a pattern. |
| **Preset** | A saved sound. *User presets* are your own sounds in the FM-1. |
| **Project** | A song in the FM-1 with its tracks and patterns. The app fetches projects one by one from their slots and writes them back. |
| **Recovery** | Help when the FM-1 no longer starts: first update mode, then – if necessary – the chip's built-in recovery mode. See [Recovery](app://page/recovery). |
| **Sample** | A short sound recording (WAV), e.g. a bass drum. |
| **Sample slot** | A storage place for a sample kit on Skiff, SLOOP and FM1 Open (USR1, USR2 … on the device). Melodee from 1.5 on has none. |
| **Simulator** | An FM-1 on the computer: try out a firmware without touching the device. Under [Firmware+ › Simulator](app://page/simulator). |
| **Slot** | A storage place in the FM-1 for a project (e.g. 32 on Melodee, 4 on SLOOP) or a user preset (384 on Melodee). The app always calls it a *slot*. |
| **Studio twin** | Your FM-1's firmware (so far Melodee) together with the complete device state on the computer – identical sound, WAV export, back to the device. [Studio](app://page/studio) page, see Help › Studio. |
| **SysEx** | Special MIDI messages with which the editor and the app exchange data with the FM-1. Visible in the MIDI monitor. |
| **Update mode** | Start mode for installing a firmware: FM-1 off, hold **OCT−**, switch on – three flashes. See [Update mode & recovery](help:03-update-modus). |
| **USB data cable** | A cable that transfers data. Charge-only cables look the same but do not work. |
