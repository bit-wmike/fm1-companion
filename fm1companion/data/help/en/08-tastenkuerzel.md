# Keyboard shortcuts

The most important shortcuts – the complete, always up-to-date list is in [Help › Keyboard shortcuts](app://action/shortcuts).

| Shortcut | Action |
|---|---|
| Ctrl+K | Command search |
| F1 | Help Center |
| Ctrl+B | Back up now |
| F5 | Reconnect |
| Ctrl+1 … Ctrl+9 | Pages in order |
| F9 | Sidebar on/off |
| F11 | Full screen |
| Ctrl+Plus / Ctrl+Minus / Ctrl+0 | Zoom in / Zoom out / Normal size |
| Ctrl+, | Settings |
| Ctrl+Q | Quit |
