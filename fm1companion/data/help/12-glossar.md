# Glossar

Die Begriffe, die in der App vorkommen – kurz erklärt. Mit der Suche oben links findest du jeden davon.

| Begriff | Bedeutung |
|---|---|
| **Backup** | Komplette Sicherung eines FM-1: Projekte, Presets und Einstellungen in einer Datei. Liegt in `~/FM-1/Backups`, je Gerät ein eigener Ordner. Siehe [Backups](app://page/backups). |
| **Custom-Firmware** | Eine Firmware, die nicht von M-VAVE stammt, z. B. Melodee, Skiff oder SLOOP. |
| **Demo-Modus** | Start mit `fm1-companion --demo`: drei simulierte FM-1, eigene Einstellungen und ein eigener Hauptordner. Deine echten Daten bleiben unberührt. |
| **Editor** | Der Web-Editor, den die installierte Firmware selbst mitbringt. Die App zeigt ihn auf der Seite [Editor](app://page/editor). |
| **Felucca** | Die Firmware-Familie, zu der Melodee, Skiff und SLOOP gehören. Sie teilen sich das Editor-Protokoll, über das die App Backups, Projekte und Presets liest und schreibt. |
| **Firmware** | Das Programm, das im FM-1 läuft. Finden, wechseln und aktualisieren auf der Seite [Firmware+](app://page/discover) (Reiter [Installieren & Versionen](app://page/firmware)). |
| **FM-Voice (DX7)** | Ein Klang im Format des Yamaha DX7. Unter Presets › FM-Voices (DX7) sammelst, hörst und erzeugst du solche Klänge und schickst sie ans FM-1. |
| **Gerät** | Ein FM-1, das die App kennt. Jedes bekommt Name, Farbe, Notizen und eigene Backups – auch wenn du zwei hast. |
| **Hauptordner** | `~/FM-1` – hier liegt alles, was du selbst anfasst: Backups, Projekte, Samples, Kits, Aufnahmen. Änderbar in den Einstellungen. |
| **Kit** | Eine Zusammenstellung von Samples, die zusammen in einen Sample-Slot des FM-1 kommt (Skiff, SLOOP). |
| **MIDI** | Die Sprache, in der Musikgeräte Noten, Regler und Takt austauschen. Die App spricht über USB-MIDI mit dem FM-1. |
| **Nur MIDI** | Eine Firmware ohne Editor-Protokoll (z. B. die Original-Firmware). Die App kann dann Noten senden und mithören, aber keine Backups oder Projekte lesen. |
| **Original-Firmware** | Die Firmware von M-VAVE (V14, V15, V16). Der Weg zurück steht unter [Firmware wechseln](help:02-firmware). |
| **Pattern** | Eine Folge von Noten auf einer Spur des FM-1. Unter Komponieren › Aus MIDI-Datei wird aus einer MIDI-Datei ein Pattern. |
| **Platz** | Ein Speicherplatz im FM-1 für ein Projekt (z. B. 32 bei Melodee, 4 bei SLOOP) oder ein User-Preset (384 bei Melodee). Die App sagt dafür immer *Platz*. |
| **Preset** | Ein gespeicherter Klang. *User-Presets* sind deine eigenen Klänge im FM-1. |
| **Projekt** | Ein Song im FM-1 mit seinen Spuren und Pattern. Die App holt Projekte einzeln von ihren Plätzen und spielt sie zurück. |
| **Rettung** | Hilfe, wenn das FM-1 nicht mehr startet: erst der Update-Modus, dann – wenn nötig – der eingebaute Rettungsmodus des Chips. Siehe [Rettung](app://page/recovery). |
| **Sample** | Eine kurze Tonaufnahme (WAV), z. B. eine Bassdrum. |
| **Sample-Slot** | Ein Speicherplatz für ein Sample-Kit bei Skiff, SLOOP und FM1 Open (am Gerät USR1, USR2 …). Hier bleibt die App beim Wort der Firmwares: *Slot*. Melodee ab 1.5 hat keine. |
| **Schlagwörter** | Stichwörter, mit denen du Samples und Backups ordnest und wiederfindest. |
| **Studio-Zwilling** | Die Firmware deines FM-1 (bisher Melodee) samt komplettem Gerätezustand im Rechner – identischer Klang, WAV-Export, zurück aufs Gerät. Seite [Studio](app://page/studio), siehe Hilfe › Studio. |
| **Simulator** | Ein FM-1 im Rechner: Firmware ausprobieren, ohne das Gerät anzufassen. Unter [Firmware+ › Simulator](app://page/simulator). |
| **SysEx** | Besondere MIDI-Nachrichten, mit denen Editor und App Daten mit dem FM-1 austauschen. Zu sehen im MIDI-Monitor. |
| **Update-Modus** | Startmodus zum Installieren einer Firmware: FM-1 aus, **OCT−** halten, einschalten – drei Lichtblitze. Siehe [Update-Modus & Rettung](help:03-update-modus). |
| **USB-Datenkabel** | Ein Kabel, das Daten überträgt. Reine Ladekabel sehen gleich aus, funktionieren aber nicht. |
