# Atajos de teclado

Los atajos más importantes – la lista completa y siempre actualizada está en [Ayuda › Atajos de teclado](app://action/shortcuts).

| Atajo | Acción |
|---|---|
| Ctrl+K | Búsqueda de comandos |
| F1 | Centro de ayuda |
| Ctrl+B | Hacer copia ahora |
| F5 | Reconectar |
| Ctrl+1 … Ctrl+9 | Páginas en orden |
| F9 | Barra lateral sí/no |
| F11 | Pantalla completa |
| Ctrl+Plus / Ctrl+Minus / Ctrl+0 | Ampliar / Reducir / Tamaño normal |
| Ctrl+, | Ajustes |
| Ctrl+Q | Salir |
