# Tastenkürzel

Die wichtigsten Kürzel – die vollständige, immer aktuelle Liste zeigt [Hilfe › Tastenkürzel](app://action/shortcuts).

| Kürzel | Aktion |
|---|---|
| Strg+K | Befehlssuche |
| F1 | Hilfe-Center |
| Strg+B | Backup jetzt |
| F5 | Neu verbinden |
| Strg+1 … Strg+9 | Seiten der Reihe nach |
| F9 | Seitenleiste ein/aus |
| F11 | Vollbild |
| Strg+Plus / Strg+Minus / Strg+0 | Oberfläche größer / kleiner / normal |
| Strg+, | Einstellungen |
| Strg+Q | Beenden |
